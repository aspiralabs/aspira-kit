# Pitfalls

Things that have bitten us. Each entry: what happened, why, what to do instead, date.

- **Tailwind v4 does not see classes inside packages.** A product must add `@source "../node_modules/@aspiralabs/ui/dist";` to its CSS or the package's markup renders unstyled. `kit init` writes this line. (2026-09-19)
- **A token override only reaches what reads the token.** `Button` in SAAS_BOILER hardcoded `rounded-none`, so `--radius-on: 1` rounded everything except buttons. Audit `rounded-*`, `text-[...]`, and hex values in components before assuming overrides work. (2026-09-19)
- **`paths` in a shared tsconfig do not work.** TypeScript resolves `paths` relative to the file that declares them, so `@aspiralabs/config/tsconfig/next.json` cannot carry `@/*`. Each project declares its own `paths`; `kit init` adds the default. (2026-09-19)
- **Tailwind must also scan the MDX docs.** Demo blocks carry classes like `gap-3`; without `@source` pointing at the docs folder they render unstyled. In a product this means `@source "../node_modules/@aspiralabs/ui/docs"` alongside the `dist` line if the product renders the docs. (2026-09-19)
- **pnpm 12 does not expand `${VAR}` in `.npmrc`.** A committed `//npm.pkg.github.com/:_authToken=${NPM_TOKEN}` line resolves to the string `undefined` and every install 401s. The token goes in `~/.npmrc` literally; the project `.npmrc` carries only the scope-to-registry line. (2026-09-19)
- **`Input` drops or loops under machine-speed typing.** react-imask's accept/state effects race when keystrokes land faster than a React commit (0ms bursts from an automation tool): characters alternate between the DOM and the emitted value, and the mask can ping-pong into "Maximum update depth". Human typing is fine; the RECIPES mask-key/sync-echo fix (ported 2026-09-19) cut the plain-Input loop from 49 to 0 in the harness but the class remains inside react-imask. Automated tests must type with a per-key delay (`{ delay: 20 }` is enough); do not feed typed text back into `Input` as `defaultValue`/`value` per keystroke from a wrapper (see `InputAddress` for the seed pattern). (2026-09-19)
- **A "skip the echo" guard must be one-shot.** RECIPES' `Input` guard compares the mask value to the last programmatic write and starts at `''`; because it was never reset, clearing a field back to `''` was silently never reported to `onValueChange`. The kit's port consumes the guard on first match. Any echo guard that compares by value needs a reset, or a real edit that happens to equal the guarded value disappears. Caught by `input-date.test.tsx` ("emits undefined when the input is cleared") the moment the tests came over. (2026-09-19)
