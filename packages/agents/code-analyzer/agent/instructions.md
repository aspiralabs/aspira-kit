Report the status (`clean`, `partial`, `nothing-detected`, `failed`), the stop reason, initial and remaining diagnostic counts, the files the model edited, rejected edits, anything unavailable, the reported cost and the output directory with `report.md`. `partial` means the analyzers still fail or one could not run; say so plainly.
