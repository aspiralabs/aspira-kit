```tsx
import { Input } from '@aspiralabs/ui';

    label="Email"
    placeholder="you@example.com"

    onValueChange={({ value }) => setEmail(value)}
/>
```

## State management

The input works in three modes. Reach for whichever matches who should own the value.

| Mode              | Who owns state | You pass                          | You read via                       |
| ----------------- | -------------- | --------------------------------- | ---------------------------------- |
| Controlled        | React          | `value` + `onValueChange`         | your state                         |
| Uncontrolled      | The field      | `defaultValue`                    | `onBlur` / `onValueChange`         |
| Form-controlled   | `<Form>`       | `name`                            | Form's `onSubmit` payload          |

### Controlled

Supply a `value` prop and the field mirrors it. The value is synced imperatively through
iMask (not by binding `value` on the native element), so React and the mask never fight
over the DOM value. Drive state with `onValueChange` (masked/typed values) or the native
`onChange` event — whichever you prefer. Because React owns the value, you can set it from
anywhere (note the buttons below).

```tsx
const [name, setName] = useState('');

// Using onValueChange (recommended for masked fields)
<Input label="Name" value={name} onValueChange={({ value }) => setName(value)} />

// Or with a plain native onChange
<Input label="Name" value={name} onChange={(e) => setName(e.target.value)} />
```

### Uncontrolled

Omit `value` and the field owns its own state. Seed it with `defaultValue` and read the
final value when you need it — on blur (with the unmasked/typed values) or on submit.

```tsx
<Input
    label="Name"
    defaultValue="Jane Doe"
    onBlur={(e, { unmaskedValue }) => save(unmaskedValue)}
/>
```

</Demo>

### Form-controlled

Inside a `<Form>`, wiring is automatic — pass a `name` matching a zod schema key and Form
threads the input through a react-hook-form `Controller`. You don't pass `value`,
`onValueChange`, `defaultValue`, or `error` yourself; Form injects them, paints validation
errors inline, and hands you the parsed payload on submit. Submit empty to see the zod
error paint.

```tsx
import { Form } from '@aspiralabs/ui';
import { Input } from '@aspiralabs/ui';
import { Button } from '@aspiralabs/ui';
import { z } from 'zod/v3';

const schema = z.object({
    email: z.string().email('Enter a valid email'),
});

<Form schema={schema} onSubmit={({ email }) => save(email)}>
    <Input name="email" label="Email" placeholder="you@example.com" />
    <Button type="submit">Submit</Button>
</Form>
```

## Props

Accepts all native `input` attributes plus the props below.

| Prop            | Type                                                       | Default   | Description                                                                                          |
| --------------- | ---------------------------------------------------------- | --------- | ---------------------------------------------------------------------------------------------------- |
| `value`         | `string \| number`                                         | —         | Controlled value, synced into the mask imperatively. Omit for uncontrolled (use `defaultValue`).     |
| `label`         | `string`                                                   | —         | Label rendered above the input.                                                                      |
| `error`         | `FormError`                                                | —         | react-hook-form error object. Shows message + destructive border.                                    |
| `icon`          | `string`                                                   | —         | Material icon name rendered inside the input on the left.                                            |
| `size`          | `default \| sm \| xs`                                      | `default` | Height tier (56 / 40 / 32 px).                                                                       |
| `mask`          | `FactoryOpts`                                              | —         | IMask mask config. See `imask`'s FactoryOpts docs.                                                   |
| `onValueChange` | `({ value, typedValue }) => void`                          | —         | Fires on value change with masked `value` and coerced `typedValue`.                                  |
| `onBlur`        | `(event, { unmaskedValue, typedValue }) => void`           | —         | Fires on blur with the event + unmasked / typed values.                                              |
