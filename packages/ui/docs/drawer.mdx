The `direction` prop controls which edge the drawer slides in from. Defaults to `right`.

## Size

`size` is a number (px) or any CSS string. Width applies on `left`/`right`; height applies on `top`/`bottom`. It sizes the card itself; the 16px inset around it is automatic, and the card is clamped to the viewport so a `size` larger than the screen never overflows.

## 1. Define the drawer

Same shape as defining a Modal. Compose the scrollable body with `Drawer.Content` and the sticky footer with `Drawer.Actions`.

```tsx
import NiceModal, { useModal } from '@ebay/nice-modal-react';
import { Drawer } from '@aspiralabs/ui';
import { Button } from '@aspiralabs/ui';

export default NiceModal.create(
    ({ assetId }: { assetId: string }) => {
        const modal = useModal();

        return (
            <Drawer modal={modal} title="Asset details" direction="right" size={420}>
                <Drawer.Content>
                    {/* scrollable body */}
                </Drawer.Content>
                <Drawer.Actions>
                    <Button variant="secondary" onClick={() => modal.hide()}>Cancel</Button>
                    <Button onClick={() => modal.hide()}>Save</Button>
                </Drawer.Actions>
            </Drawer>
        );
    },
);
```

## 2. Invoke it from anywhere

```tsx
import NiceModal from '@ebay/nice-modal-react';
import AssetDetailsDrawer from '@/components/drawers/asset-details-drawer';

NiceModal.show(AssetDetailsDrawer, { assetId: 'abc123' });
```

## Props

| Prop             | Type                              | Default | Description                                                                                |
| ---------------- | --------------------------------- | ------- | ------------------------------------------------------------------------------------------ |
| `modal`          | `NiceModalHandler`                | —       | Required. Result of `useModal()`.                                                          |
| `children`       | `ReactNode`                       | —       | Usually `Drawer.Content` + `Drawer.Actions`.                                               |
| `title`          | `string`                          | —       | Renders a header with title + close button when present.                                   |
| `direction`      | `top \| bottom \| left \| right`  | `right` | Which edge the drawer slides in from.                                                      |
| `size`           | `number \| string`                | `500`   | Card width for left/right, height for top/bottom. Number = px; string = any CSS value. Clamped to the viewport. |
| `onOutsideClick` | `() => void`                      | —       | Fires before the drawer hides on backdrop click / ESC.                                     |
| `className`      | `string`                          | —       | Merged onto the panel.                                                                     |
