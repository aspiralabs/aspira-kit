---
eyebrow: Scroll Area
title: ScrollArea
group: Layout
description: Styled scrollable container built on Radix ScrollArea — cross-platform custom scrollbars that don't eat layout width. Takes arbitrary children. For a data-driven, list-virtualized version, see VirtualizedScrollArea. Import from @aspiralabs/ui.
---

## Usage

```tsx
import { ScrollArea } from '@aspiralabs/ui';

<ScrollArea className="h-64 rounded-md border">
    <div className="p-4">{/* any content */}</div>
</ScrollArea>
```

## Props

Accepts every Radix ScrollArea Root prop plus the additions below.

| Prop                | Type                       | Default    | Description                                                                            |
| ------------------- | -------------------------- | ---------- | -------------------------------------------------------------------------------------- |
| `orientation`       | `vertical \| horizontal`   | `vertical` | Which axis the scrollbar tracks.                                                       |
| `className`         | `string`                   | —          | Applied to the root — commonly sets height.                                            |
| `viewPortClassName` | `string`                   | —          | Applied to the Radix Viewport. Use when the inner scroll surface needs custom styling. |
| `viewPortRef`       | `Ref<HTMLDivElement>`      | —          | Ref to the Viewport — used by VirtualizedScrollArea for virtual list anchoring.        |
