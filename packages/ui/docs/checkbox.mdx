## Usage

```tsx
import { Checkbox } from '@aspiralabs/ui';

<Checkbox id="terms" checked={checked} onCheckedChange={setChecked} />
```

## States

Unchecked, checked, disabled (each combination).

## Props

All props from Radix `Checkbox.Root` pass through — only common ones listed here.

| Prop              | Type                            | Default | Description                                  |
| ----------------- | ------------------------------- | ------- | -------------------------------------------- |
| `checked`         | `boolean \| "indeterminate"`    | —       | Controlled state.                            |
| `defaultChecked`  | `boolean`                       | `false` | Uncontrolled initial state.                  |
| `onCheckedChange` | `(checked) => void`             | —       | Fires on toggle with the new checked value.  |
| `disabled`        | `boolean`                       | `false` | Disables interaction.                        |
| `className`       | `string`                        | —       | Merged onto the root.                        |
