eyebrow: Segmented Control
title: SegmentedControl
group: Actionable
description: Inline toggle group for mutually-exclusive choices — grid/list views, month/year billing, etc. Items are passed declaratively with `value`, `label`, optional `icon`, and `tooltip` (icon-only items). Fully generic over the value type. Import from @aspiralabs/ui.
---

export const LabelIconDemo = () => {
    const [view, setView] = useState('grid');
    return (
        <SegmentedControl
            value={view}
            onChange={setView}
            items={[
                { value: 'grid', label: 'Grid', icon: 'grid_view' },
                { value: 'list', label: 'List', icon: 'view_list' },
                { value: 'board', label: 'Board', icon: 'view_kanban' },
            ]}
        />
    );
};

## Usage

```tsx
import { SegmentedControl } from '@aspiralabs/ui';

<SegmentedControl
    value={view}
    onChange={setView}
    items={[
        { value: 'grid', label: 'Grid', icon: 'grid_view' },
        { value: 'list', label: 'List', icon: 'view_list' },
    ]}
/>
```

## Props

| Prop        | Type                    | Default   | Description                              |
| ----------- | ----------------------- | --------- | ---------------------------------------- |
| `items`     | `SegmentedControlItem[]`| —         | See item shape below.                    |
| `value`     | `T`                     | —         | Controlled selection.                    |
| `onChange`  | `(value: T) => void`    | —         | Fires on segment click with the new value.|
| `size`      | `sm \| default`         | `default` | Height tier.                             |
| `className` | `string`                | —         | Applied to the root group wrapper.       |

## SegmentedControlItem shape

| Key         | Type        | Required | Description                                                      |
| ----------- | ----------- | -------- | ---------------------------------------------------------------- |
| `value`     | `T`         | yes      | Passed back via onChange.                                        |
| `label`     | `ReactNode` | —        | Visible text. Omit for icon-only segments.                       |
| `icon`      | `string`    | —        | Material icon name.                                              |
| `tooltip`   | `string`    | —        | Shown only on icon-only segments (when no `label`).              |
| `ariaLabel` | `string`    | —        | Accessible label for the button. Recommended for icon-only items.|
| `badge`     | `ReactNode` | —        | Optional pill badge shown beside the label (e.g. a "20% Off" promo).|
