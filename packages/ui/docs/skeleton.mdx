description: Minimal loading placeholder — just a pulsing bg-surface div. Shape comes from whatever className you pass (height, width, rounding). Accepts all native div props. Import from @aspiralabs/ui.
---

## Usage

```tsx
import { Skeleton } from '@aspiralabs/ui';

<Skeleton className="h-10 w-full rounded-md" />
<Skeleton className="size-12 rounded-full" />
```

## Shapes

Size and shape are entirely up to you — pass width, height, and rounding via Tailwind.

<Demo>
    <div className="flex items-center gap-4 flex-wrap">
        <Skeleton className="h-4 w-48 rounded" />
        <Skeleton className="h-10 w-32 rounded-md" />
        <Skeleton className="size-12 rounded-full" />
        <Skeleton className="size-16 rounded-lg" />
        <Skeleton className="h-24 w-24 rounded-2xl" />
    </div>
</Demo>

## Props

Accepts every native `div` prop.

| Component  | Prop        | Type     | Default | Description                                                                                            |
| ---------- | ----------- | -------- | ------- | ------------------------------------------------------------------------------------------------------ |
| `Skeleton` | `className` | `string` | —       | Merged after the defaults (`bg-surface animate-pulse`). Drives size, rounding, and any overrides.      |
