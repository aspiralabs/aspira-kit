## Usage

```tsx
import { Badge } from '@aspiralabs/ui';

<Badge variant="blue">New</Badge>
```

## Color variants

Named colors — pick by semantic meaning, or see aliases below.

<Demo>
    <div className="flex flex-wrap gap-2">

        <Badge variant="blue">Blue</Badge>
        <Badge variant="green">Green</Badge>
        <Badge variant="orange">Orange</Badge>
        <Badge variant="pink">Pink</Badge>
        <Badge variant="purple">Purple</Badge>
        <Badge variant="indigo">Indigo</Badge>
    </div>
</Demo>

## Semantic aliases

Use these when the meaning matters more than the color — they map to the named colors but make intent explicit at call sites.

<Demo>
    <div className="flex flex-wrap gap-2">

</Demo>

## Props

| Prop        | Type                                                                                                                  | Default   | Description                                                              |
| ----------- | --------------------------------------------------------------------------------------------------------------------- | --------- | ------------------------------------------------------------------------ |
| `variant`   | `gray \| blue \| green \| orange \| pink \| purple \| indigo \| default \| secondary \| destructive \| warning \| brand \| accent \| outline` | `gray`    | Color / tone.                                                            |
| `size`      | `sm \| default \| lg \| xl`                                                                                            | `default` | Padding + font-size tier.                                                |
| `asChild`   | `boolean`                                                                                                              | `false`   | Render as the single child (via Radix Slot) — use to style an `<a>` or `<button>`. |
| `className` | `string`                                                                                                               | —         | Merged after variants.                                                   |
