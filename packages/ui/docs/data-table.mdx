Lives in `components/ui/tables/` — a dedicated tier for heavy, feature-rich composites built on top of primitives and core components. Separate from `core/` because data tables carry substantial business logic.

## Usage

```tsx
import { DataTable } from '@aspiralabs/ui';
import { ColumnDef } from '@tanstack/react-table';

type User = { id: string; name: string; email: string };

const columns: ColumnDef<User>[] = [
    { accessorKey: 'name', header: 'Name' },
    { accessorKey: 'email', header: 'Email' },
];

<DataTable
    columns={columns}
    data={users}
    onRowClick="/users/<id>"  // optional — URL template with <field> tokens
/>
```

## Loading

`loading` keeps the header and swaps the rows for skeleton placeholders, so the table does not collapse while data is on the way.

<Demo>
    <DataTable columns={DATA_TABLE_DEMO_COLUMNS} data={[]} loading skeletonRows={3} />
</Demo>

## Props

| Prop         | Type                | Default | Description                                                                                                                |
| ------------ | ------------------- | ------- | -------------------------------------------------------------------------------------------------------------------------- |
| `columns`    | `ColumnDef<T>[]`    | —       | TanStack Table column definitions. Set `size` on a column to give it a fixed width.                                        |
| `data`       | `T[]`               | —       | Full dataset. Pagination is client-side.                                                                                   |
| `onRowClick` | `string`            | —       | URL template. Tokens `<fieldName>` are replaced from the row's data. Clicks on buttons / links inside the row are ignored. |
| `hideHeader` | `boolean`           | `false` | Skips the table header row.                                                                                                |
| `loading`    | `boolean`           | `false` | Keep the header, render skeleton rows instead of data.                                                                     |
| `skeletonRows` | `number`          | `5`     | How many skeleton rows to show while `loading`.                                                                            |
