        toast.promise(…)

);

## Usage

```tsx
import { toast } from 'sonner';

// Success
toast.success('Profile updated');

// Error
toast.error('Something went wrong', {
    description: 'Check your connection and try again.',
});

// Neutral
toast('Heads up — your session expires in 5 minutes');

// With an action
toast('Item archived', {
    action: {
        label: 'Undo',
        onClick: () => restore(),
    },
});

// Promise — auto-resolves to success/error with a loading state
toast.promise(saveChanges(), {
    loading: 'Saving…',
    success: 'Saved',
    error: 'Failed to save',
});
```

## Common APIs

| Call                              | Purpose                                                                          |
| --------------------------------- | -------------------------------------------------------------------------------- |
| `toast(message, options?)`        | Neutral toast.                                                                   |
| `toast.success(message, options?)`| Positive feedback after a successful action.                                     |
| `toast.error(message, options?)`  | Failure state — the most common pattern in error handlers.                       |
| `toast.info / toast.warning`      | Informational / warning variants when you need to distinguish from neutral/error.|
| `toast.loading(message)`          | Spinner toast — returns an id you can update via toast.success/error later.      |
| `toast.promise(p, states)`        | Shortcut for loading → success/error from a promise.                             |
| `toast.dismiss(id?)`              | Dismiss a specific toast (by id) or all toasts.                                  |

## Common options

| Option                   | Type                       | Description                                                                                              |
| ------------------------ | -------------------------- | -------------------------------------------------------------------------------------------------------- |
| `description`            | `string \| ReactNode`      | Sub-line under the title.                                                                                |
| `action`                 | `{ label, onClick }`       | Renders a button inside the toast (e.g. Undo).                                                           |
| `duration`               | `number`                   | Milliseconds before auto-dismiss. Default: 4000.                                                         |
| `id`                     | `string \| number`         | Stable id — reuse to update an existing toast (e.g. promote a loading toast to success).                 |
| `onDismiss / onAutoClose`| `(t) => void`              | Fires when the toast closes (manually / automatically).                                                  |
