## Usage

```tsx
import { Icon } from '@aspiralabs/ui';

<Icon icon="home" />
<Icon icon="favorite" fill />
<Icon icon="settings" size={32} weight={700} />
```

The Material Symbols name comes from the [Material Symbols catalog](https://fonts.google.com/icons). Custom SVG icons live in `components/ui/core/icon/custom-icons.tsx` and shadow Material names when present.

## Custom icons

Project-local SVGs live in `components/ui/core/icon/custom-icons.tsx` under the `CUSTOM_ICONS` registry. Reference them by their registry key — `<Icon>` resolves the SVG before falling through to Material Symbols, so a custom name will shadow a Material name if both exist. Material-Symbols-only props (`fill`, `weight`, `grade`) are ignored for SVG icons since they have no analog outside the variable font.

Add an entry to the registry, then use it the same way:

```tsx
<Icon icon="magnify-alt" size={20} className="text-foreground-subtext" />
```

<Demo>

    </div>
</Demo>

## Props

| Prop        | Type                  | Default | Description                                                                                |
| ----------- | --------------------- | ------- | ------------------------------------------------------------------------------------------ |
| `icon`      | `string`              | —       | Material Symbols name (e.g. `home`, `more_vert`) or a custom registry key (e.g. `magnify-alt`). |
| `size`      | `number`              | `24`    | Pixel size. Sets font-size, width, height, and `opsz` together.                            |
| `fill`      | `boolean`             | `false` | Switches to the filled variant. Material Symbols only.                                     |
| `weight`    | `100–700 (step 100)`  | `400`   | Stroke weight. Material Symbols only.                                                      |
| `grade`     | `number`              | `0`     | Grade variation (negative thins, positive thickens). Use subtle values. Material Symbols only. |
| `className` | `string`              | —       | Applied to the wrapper span; use for color.                                                |
