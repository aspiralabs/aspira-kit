## Usage

```tsx
import { Textarea } from '@aspiralabs/ui';

<Textarea
    label="Bio"
    placeholder="Tell us about yourself…"
    value={bio}
    onChange={(e) => setBio(e.target.value)}
/>
```

## Auto-grow

The textarea uses CSS `field-sizing: content` — its height grows as you type. Minimum height is `min-h-16` (64px).

<Demo>
    <div className="max-w-md">
        <Textarea
            label="Long note"
            placeholder="Start typing — the field will grow as you add lines."
        />
    </div>
</Demo>

## Props

Accepts all native `textarea` attributes plus the props below.

| Prop        | Type        | Description                                                                            |
| ----------- | ----------- | -------------------------------------------------------------------------------------- |
| `label`     | `string`    | Optional label rendered above.                                                         |
| `error`     | `FormError` | react-hook-form error object. Shows destructive border and the message below the field. |
| `className` | `string`    | Merged onto the textarea element.                                                      |
