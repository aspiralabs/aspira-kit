## Usage

```tsx
import { Card, CardHeader, CardTitle, CardDescription, CardContent, CardFooter } from '@aspiralabs/ui';

<Card>
    <CardHeader>
        <CardTitle>Title</CardTitle>
        <CardDescription>Supporting copy.</CardDescription>
    </CardHeader>
    <CardContent>Body content.</CardContent>
    <CardFooter>Actions</CardFooter>
</Card>
```

## Basic

Header (title + description) over content.

<Demo>
    <div className="max-w-md">

## With header action

`CardAction` inside a `CardHeader` pins to the top-right via the header's grid.

## Sub-components

| Export            | Slot               | Notes                                                                          |
| ----------------- | ------------------ | ------------------------------------------------------------------------------ |
| `Card`            | `card`             | Root container. Border, rounded, padded, flex-column.                          |
| `CardHeader`      | `card-header`      | Grid wrapper — title/description stacked, optional action on the right.        |
| `CardTitle`       | `card-title`       | text-2xl, semibold.                                                            |
| `CardDescription` | `card-description` | text-sm, muted.                                                                |
| `CardAction`      | `card-action`      | Self-ends to the top-right of the header grid.                                 |
| `CardContent`     | `card-content`     | Unstyled body slot.                                                            |
| `CardFooter`      | `card-footer`      | Flex row. Use `[.border-t]` to opt into a top border.                          |
