description: Windowed list renderer for long arrays — only renders the items currently in view plus a small overscan. Built on @tanstack/react-virtual and composes the core ScrollArea. Data-driven — takes items[] + renderItem. Import from @aspiralabs/ui.

export const demoItems = Array.from({ length: 10000 }, (_, i) => i);

## Usage

```tsx
import { VirtualizedScrollArea } from '@aspiralabs/ui';

<VirtualizedScrollArea
    items={rows}
    listHeight={400}
    estimateSize={() => 44}
    getItemKey={(i) => rows[i].id}
    renderItem={(row) => <Row data={row} />}
/>
```

## 10,000-row demo

Ten thousand items rendered in a 400px viewport. Only the visible slice is in the DOM —
inspect the element to see the window.

## Props

| Prop            | Type                                          | Default | Description                                                                                  |
| --------------- | --------------------------------------------- | ------- | -------------------------------------------------------------------------------------------- |
| `items`         | `T[]`                                         | —       | The array to virtualize.                                                                     |
| `renderItem`    | `(item: T, index: number) => ReactNode`       | —       | Renders one row.                                                                             |
| `listHeight`    | `number`                                      | —       | Viewport height in pixels.                                                                   |
| `estimateSize`  | `(index: number) => number`                   | —       | Estimated row height. Constant for equal rows, index-driven otherwise.                       |
| `getItemKey`    | `(index: number) => string \| number`         | `index` | Stable React key per row — use the item's id for correct reconciliation.                     |
| `overscan`      | `number`                                      | `5`     | Rows rendered beyond the visible window — smooths scroll perceptual feel.                    |
| `initialScroll` | `{ index, clickAfterScroll }`                 | —       | Scroll to index on mount, optionally auto-click the first child of that row.                 |
| `className`     | `string`                                      | —       | Forwarded to the inner ScrollArea root.                                                      |
